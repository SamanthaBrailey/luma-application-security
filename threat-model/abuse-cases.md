# Abuse Cases

## Account and identity abuse

- Automated account registration
- Credential stuffing and password spraying
- Username or email enumeration
- Password-reset abuse
- Session theft
- Impersonation and cloned profiles

## Content and community abuse

- Spam and coordinated inauthentic activity
- Harassment and abusive content
- Malicious links
- Stored cross-site scripting attempts
- Scraping of public or private information
- Reporting-system abuse

## Technical abuse

- Changing resource identifiers to access another user's data
- Bypassing client-side restrictions with direct API requests
- Uploading files with misleading extensions or content types
- Sending requests faster than expected to exhaust resources
- Extracting secrets from client code, error messages, or repositories

## Questions for each abuse case

1. Can the action be prevented?
2. Can it be detected quickly?
3. What evidence would be logged?
4. How would the affected user recover?
5. What control would reduce the risk without harming normal users?
